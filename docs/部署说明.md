# 学生选课管理系统 — 部署说明

## 一、环境要求

| 软件 | 版本建议 | 说明 |
|------|----------|------|
| JDK | 1.8 或 11 | 后端运行环境 |
| Maven | 3.6+ | 后端构建 |
| Node.js | 14 / 16 / 18 LTS | 前端构建 |
| npm | 随 Node 安装 | 前端依赖安装 |
| MySQL | 5.7 / 8.0 | 业务数据库 |
| 浏览器 | Chrome / Edge | 访问管理端 |

## 二、数据库初始化

1. 启动 MySQL 服务。
2. 使用 Navicat、DBeaver、命令行等方式连接数据库。
3. 执行项目中的脚本：

```text
sql/course_selection.sql
```

脚本会自动：

- 创建数据库 `course_selection`
- 创建全部业务表
- 插入演示数据（管理员、学生、教师、课程、排课、选课、成绩、公告、限制）

默认管理员：

- 用户名：`admin`
- 密码：`admin123`

如需修改数据库名，请同步修改后端 `application.yml` 中的 JDBC URL。

## 三、后端部署

### 3.1 修改配置

打开文件：

```text
backend/src/main/resources/application.yml
```

重点修改：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/course_selection?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
    username: root
    password: your_mysql_password   # 改成你的 MySQL 密码；或使用 application-local.yml
```

服务端口默认 `8088`，上下文路径 `/api`，即接口根地址：

```text
http://localhost:8088/api
```

### 3.2 启动方式（开发）

在 `backend` 目录执行：

```bash
mvn spring-boot:run
```

或使用 IDEA：打开 `CourseApplication.java`，右键 Run。

启动成功后控制台会打印：

```text
学生选课管理系统启动成功
接口地址: http://localhost:8088/api
```

### 3.3 打包运行（生产）

```bash
cd backend
mvn clean package -DskipTests
java -jar target/student-course-system-1.0.0.jar
```

## 四、前端部署

### 4.1 安装依赖

```bash
cd frontend
npm install
```

若国内网络较慢，可使用：

```bash
npm install --registry=https://registry.npmmirror.com
```

### 4.2 开发模式启动

```bash
npm run serve
```

默认访问：

```text
http://localhost:8080
```

开发环境已配置代理：前端请求 `/api/**` 会转发到 `http://localhost:8088`。

### 4.3 生产构建

```bash
npm run build
```

产物在 `frontend/dist`。可将 `dist` 部署到 Nginx，并反向代理 `/api` 到后端。

示例 Nginx 配置：

```nginx
server {
    listen 80;
    server_name localhost;
    root /usr/share/nginx/html;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8088/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 五、登录验证

1. 浏览器打开前端地址。
2. 输入 `admin` / `admin123`。
3. 进入首页可看到学生、教师、课程等统计卡片。
4. 左侧菜单分别验证各模块的增删改查。

## 六、常见问题

### 1. 后端启动报错：Access denied for user

MySQL 用户名或密码不正确，检查 `application.yml`。

### 2. 后端启动报错：Unknown database

未执行 SQL 脚本，或数据库名不一致。

### 3. 前端登录提示网络错误 / 401

- 确认后端已启动且端口为 8088
- 确认前端代理配置正确
- 清除浏览器 localStorage 后重新登录

### 4. 时区或时间显示异常

JDBC URL 已包含 `serverTimezone=Asia/Shanghai`，请确认本机时区设置。

### 5. npm install 失败

切换镜像源，或检查 Node 版本是否过低/过高。建议使用 Node 16/18。

### 6. 选课提示容量已满

排课记录的 `selected_count` 已达到 `capacity`，可在排课管理中调大容量，或删除部分选课记录。

## 七、付费部署指导说明（可选）

若需要远程协助部署，建议提前准备：

1. 服务器公网 IP / 远程桌面账号（或本地 TeamViewer / 向日葵）
2. 已安装 JDK、Maven、Node、MySQL
3. 明确 MySQL root 密码
4. 需要绑定的域名（如有）

远程部署通常包含：环境检查、导入数据库、修改配置、启动前后端、Nginx 发布、登录验收。
