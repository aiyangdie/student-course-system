# 学生选课管理系统 — 接口说明

统一响应格式：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

鉴权：除 `/auth/login` 外，请求头需携带：

```text
Authorization: Bearer <token>
```

基础地址：`http://localhost:8088/api`

## 认证

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /auth/login | 登录，返回 token |
| GET | /auth/info | 当前管理员信息 |
| POST | /auth/logout | 退出登录 |

登录请求体：

```json
{ "username": "admin", "password": "admin123" }
```

## 通用 CRUD 约定

多数模块支持：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /{module}/page?page=1&size=10&keyword= | 分页查询 |
| GET | /{module}/list | 下拉列表 |
| GET | /{module}/{id} | 详情 |
| POST | /{module} | 新增 |
| PUT | /{module} | 修改 |
| DELETE | /{module}/{id} | 删除 |

模块与路径映射：

| 模块 | module |
|------|--------|
| 学生 | student |
| 教师 | teacher |
| 课程 | course |
| 公告 | announcement |
| 排课 | schedule |
| 选课 | selection |
| 选课限制 | limit |
| 成绩 | grade |

## 首页统计

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /dashboard/stats | 返回学生/教师/课程/排课/选课/公告数量 |

## 选课业务规则

新增选课时后端校验：

1. 同一学生不可重复选择同一排课
2. 排课必须存在且状态为开课
3. 已选人数不可超过容量
4. 选课成功后 `selected_count + 1`
5. 删除已选记录时 `selected_count - 1`

## 成绩业务规则

若未手动填写总评，且平时分、考试分均存在，则：

```text
总评 = 平时成绩 × 0.4 + 考试成绩 × 0.6
```
